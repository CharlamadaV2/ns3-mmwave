Compute the (dx, dy) translation that maps the field anchor to the sim anchor.

The field anchor's mean ENU position is shifted so it coincides with the anchor's XY position in nodes.json. The same offset is applied to all other nodes to preserve relative geometry.

Map field timestamps onto the sim timeline.

Three modes are supported:

  • raw — relative field time used directly (t[0] subtracted).
  • scale — relative time stretched/compressed so the last point lands at target_s.
  • clip — relative time capped at target_s; points beyond are clamped to the cap value.
Parameters
t1-D time array (seconds since epoch or arbitrary origin).
modeOne of "raw", "scale", "clip".
target_sTarget duration in seconds (required for clip/scale).
Returns
Relative time array starting at 0.
Exceptions
ValueErrorfor an unrecognised mode string.

Patch one scenario's nodes.json with field-derived waypoints.

Full pipeline in one call:

  1. Load the field GPS trace for the corresponding field scenario.
  2. Skip the scenario if the target node's bbox is below _MOBILE_BBOX_M (the node was stationary in the field).
  3. Compute the frame-alignment offset from the anchor node.
  4. Apply the offset and optionally rescale/clip the time axis.
  5. Downsample to n_waypoints uniformly-spaced-in-time points.
  6. Write the waypoints into nodes.json (unless dry_run is set).
Parameters
sim_dirScenario directory containing nodes.json.
nodeID of the node to author waypoints for (default: "rab2").
anchorID of the stationary alignment anchor (default: "rab1").
n_waypointsTarget waypoint count after downsampling (default: 20).
time_modeOne of "raw", "scale", "clip" (default: "raw").
durationTarget duration in seconds for clip/scale modes.
field_zOverride z-value for all waypoints; default keeps existing node z.
field_scenarioOverride the field scenario name (else derived from sim name).
dry_runIf True, report what would be done without writing nodes.json.
mobile_bbox_mBbox threshold below which the node is treated as static.
Returns
One-line status string starting with "patched", "skipped: ...", or "error: ...".
