Detailed Description

Symmetric N×N link-quality matrix, updated each simulation tick.

Holds one LinkResult per ordered node pair. Diagonal entries (Get(i,i)) return a default-constructed LinkResult (all zeros / sentinels) and should not be used for routing or metrics.

uint32_t mesh_sim::LinkTable::ConnectedLinkCount ( double  sinrThresholdDb = -6.7) const

Count unordered node pairs whose SINR meets the threshold.

A pair is "connected" when its SINR is at or above sinrThresholdDb, meaning it can carry at least the minimum MCS rate (SINR_MIN_DB = −6.7 dB by default).

Parameters

void mesh_sim::LinkTable::Update ( uint32_t  numNodes,

Rebuild the matrix from a fresh set of link evaluations.

Replaces the entire table with the results from LinkEvaluator::EvaluateAll. Each result is stored at both [tx_id][rx_id] and [rx_id][tx_id] to make all lookups O(1).

Parameters
numNodesNumber of nodes N; determines the expected result count of N·(N−1)/2 and the matrix dimensions.
resultsFlat vector of link results from LinkEvaluator::EvaluateAll, in the same (i < j) index order.
Exceptions
std::runtime_errorif results.size() ≠ numNodes·(numNodes−1)/2.
