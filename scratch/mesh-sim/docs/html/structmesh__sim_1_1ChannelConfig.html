Detailed Description

Complete radio and channel configuration for a simulation run.

Parameters shared between the 3GPP and NYU models are at the top level. NYU-specific parameters live in the nyu sub-struct.

Gain values (tx_array_gain_dbi, rx_array_gain_dbi) represent peak directional beamforming gain per side and are applied symmetrically; each node uses the same antenna model.
