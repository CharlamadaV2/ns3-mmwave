Count the total number of peer-MAC bh2 rows seen for each local MAC.

Aggregates row counts from tag_sta_mac across every scenario, grouped by tag_local_mac. Used by main to annotate which MACs in a collision group were actively communicating and which were passive.

Returns
Mapping from local MAC address string to total number of peer-facing bh2 rows observed across all scenarios.

private

Scan all bh2.csv files and return one row per unique (rab, mac, netdev, device_name, host).

Iterates every scenario and node directory under CSV_ROOT, reads tag_local_mac, tag_interface, tag_device_name, and tag_host from each bh2.csv, and deduplicates the result. Files missing any of the required columns are silently skipped.

Returns
DataFrame with columns ["rab", "mac", "netdev", "device_name", "host"], deduplicated across all scenarios. Empty if no bh2.csv files are found.

◆ main()

int scratch.mesh-sim.scripts.arpo_data.topology_audit.main ( )

Report (rab, netdev) keys whose MAC address is claimed by more than one device.

Calls _scan to build the full (rab, mac, netdev, device_name, host) inventory and _peer_counts to annotate activity levels. For each collision it prints whether the duplicate MACs share the same chassis (same-chassis card swap) or represent two physically distinct boxes merged under one hostname.

Returns
0 if no collisions are found or all collisions are reported successfully; 1 if no bh2.csv files exist under CSV_ROOT.
