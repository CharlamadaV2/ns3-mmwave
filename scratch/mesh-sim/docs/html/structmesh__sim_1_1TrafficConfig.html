Detailed Description

Flow-level traffic demand configuration.

Three traffic models are supported, selected by model:

model Behaviour
"constant" All flows are active for the full simulation at demand_mbps.
"poisson" New flows arrive at arrival_rate_hz (network-wide Poisson process). Each flow has an exponentially distributed holding time when holding_time_s > 0, otherwise it is permanent.
"on_off" Each flow alternates between ON (sending at demand_mbps) and OFF phases. Phase durations are drawn from exponential distributions with means on_time_s and off_time_s respectively.

Three flow topologies are supported, selected by flow_topology:

flow_topology Behaviour
"all_pairs" One flow per unordered node pair (N*(N-1)/2 flows total).
"random_pairs" random_pair_count flows with uniformly random src/dst.
"gateway" Every non-gateway node sends to the gateway node.
