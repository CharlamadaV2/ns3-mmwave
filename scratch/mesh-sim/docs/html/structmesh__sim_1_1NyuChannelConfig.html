Detailed Description

Parameters specific to the NYU mmWave channel model.

These fields are only applied when ChannelConfig::channel_model is "nyu". They are silently ignored for the "3gpp" model.

ns-3 attribute names are shown in comments so they can be cross-referenced with NYUChannelModel / NYUPropagationLossModel documentation.
