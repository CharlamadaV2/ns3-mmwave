Detailed Description

Filesystem locations and per-file conventions for ARPO-style datasets.

Defaults target the bundled Spring Lake zip under data/. Callers that analyse a different bundle should construct their own DatasetPaths instead of relying on the module-level aliases at the bottom of this file.

Directory layout expected after extraction:

data/
arpo_spring_lake_data.zip
arpo_extracted/
csv/
<scenario>/
<node>/
bh2.csv
gps.csv | geotak_gps.csv
_plots/
per_day/
multi_day/
