Detailed Description

Per-scenario CSV loaders for backhaul-radio and GPS data.

Clock skew handling Node clocks drift relative to each other, so raw timestamps are not directly comparable across nodes. All loaders add a __sec__ column containing seconds since each session's first sample, making cross-session time axes directly comparable.

Column conventions

Column Type Description
__node__ str Node directory name (chassis hostname).
__session__ str Session identifier; same as __node__.
__t__ datetime (UTC) Parsed timestamp.
__sec__ float Seconds since session start.
__peer__ str Peer label resolved via topology (bh2 only).
__lat__ float Latitude in decimal degrees (GPS only).
__lon__ float Longitude in decimal degrees (GPS only).

All public loaders return DataFrame | None; None means no usable data was found for this scenario.

pd.DataFrame | None scratch.mesh-sim.scripts.arpo_data.loaders.load_bh2_scenario ( Path  scen_dir)

Load and concatenate every node's bh2.csv for a scenario.

Backhaul-2 (bh2) logs contain per-link radio metrics sampled at the driver level: SNR, RCPI, MCS (TX/RX), byte counters, PER, and AGC.

Steps performed:

  1. Discover all node subdirectories (skipping sdwan).
  2. Coerce all numeric field columns with errors="coerce" so bad rows become NaN rather than causing type errors downstream.
  3. Resolve peer MACs to human-readable labels via build_topology.
  4. Add __sec__ via session_relative_seconds.
  5. Store the topology map in df.attrs["topology"] for plot functions.
Parameters
scen_dirPath to the scenario directory (contains one subdir per node).
Returns
Concatenated DataFrame, or None if no bh2.csv files were found.

◆ load_gps_scenario()

pd.DataFrame | None scratch.mesh-sim.scripts.arpo_data.loaders.load_gps_scenario ( Path  scen_dir)

Load and concatenate GPS fixes for every node in a scenario.

Two GPS source formats are supported, in priority order:

  1. geotak_gps.csv — columns lat, lon, time (ISO-8601).
  2. gps.csv — columns field_lat, field_lon, timestamp (nanoseconds since epoch).

Rows with latitude=0 and longitude=0 are dropped as "no fix" sentinels.

Parameters
scen_dirPath to the scenario directory.
Returns
Concatenated DataFrame with __lat__, __lon__, __sec__ columns, or None if no GPS data is available.

Compute seconds elapsed since each session's earliest __t__ value.

Groups by __session__ if present, otherwise by __node__. This normalises clock skew so that t=0 is the first sample for each node.

Parameters
dfDataFrame with __t__ (datetime) and either __session__ or __node__ columns.
Returns
Float Series of relative seconds, aligned to the input index.
