Detailed Description

Writes per-tick CSV snapshots for GUI and offline plotting.

VizWriter maintains six open CSV files for the duration of the simulation and appends one row (or one row per node/link/flow) each time WriteTick is called. Writes are rate-limited to viz_tick_ms intervals so a small tick step (tick_s) does not inflate file sizes unnecessarily.

Output files (all written to cfg.output_dir)

File Columns
positions.csv time_s, node_id, x, y, z, node_type, active
links.csv time_s, node_a, node_b, dist_m, sinr_db, condition, condition_reason, capacity_mbps, delivered_mbps, hop_count
rx-power.csv time_s, node_a, node_b, rx_power_dbm
mcs.csv time_s, node_a, node_b, mcs_index, spectral_eff
flows.csv time_s, src, dst, demand_mbps, delivered_mbps, latency_ms, hop_count, routable
routes.csv time_s, src, dst, path, bottleneck_mbps, hop_count, routable
