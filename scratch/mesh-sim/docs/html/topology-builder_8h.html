Detailed Description

Creates ns-3 mobility models, buildings, and propagation models for the mesh topology.

TopologyBuilder is the only layer in mesh-sim that creates ns-3 objects. All other subsystems receive the resulting pointers via the accessor methods and operate entirely through the domain types defined in src/domain/. No EPC, RRC, MAC, or protocol stack is created.

Mobility models

NodeSpec::mobility ns-3 class Notes
"fixed" ConstantPositionMobilityModel Position set from NodeSpec::position.
"constant_velocity" ConstantVelocityMobilityModel Position and velocity set after install.
"random_walk" RandomWalk2dMobilityModel Direction changes every 1 simulated second; bounds and speed from RandomWalkParams.
"waypoint" WaypointMobilityModel All Waypoint entries added via ns3::Seconds(wp.t).

Channel condition model selection When cfg.buildings is non-empty a BuildingsChannelConditionModel is installed, giving deterministic LOS/NLOS based on building geometry. When no buildings are configured the propagation model's default statistical condition model is used instead.
