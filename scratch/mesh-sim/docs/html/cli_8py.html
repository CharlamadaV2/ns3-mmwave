Detailed Description

Main script to be ran for manipulating ARPO data as desired.

Provides a command line interface that can do one of the following commands:

  • Extract unzips data folder into extraction target direction
  • Multi-day compares day vs day data for multi day scenarios
  • Plot generates figures for specific scenario or all scenarios per individual day

int scratch.mesh-sim.scripts.arpo_data.cli.main ( )

Takes command line arguements to interact with ARPO data.

There are three arguments to be taken: "extract", "plot", or "multi-day" The extract arg will execute the extraction script The plot arg will execute the _com_plot function passing args for all or specific scenario The multi-day will execute the multi_day script

Returns
result of "extract", "_cmd_plot", or "multi_day" on success, returns 1 if the argument does not exist
