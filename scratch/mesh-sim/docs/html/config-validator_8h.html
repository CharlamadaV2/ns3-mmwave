Detailed Description

Post-load validation of a fully populated SimConfig.

Domain Rules enforced
Timing duration_s > 0; tick_s > 0; tick_s <= duration_s; warmup_s >= 0; warmup_s < duration_s
Nodes At least 2 nodes; each node's mobility and node_type must be a recognised value; waypoint nodes require >= 2 waypoints with strictly monotonically increasing times and a non-negative first timestamp
Channel frequency_ghz > 0; bandwidth_mhz > 0; channel_model ∈ {3gpp, nyu}; scenario ∈ {UMi, UMa, RMa, InH, InF}; both array gains >= 0
Traffic model ∈ {constant, poisson, on_off}; flow_topology ∈ {all_pairs, random_pairs, gateway}; demand_mbps > 0; gateway topology requires a non-empty gateway_node_id that matches a node; random_pairs requires random_pair_count > 0
Routing algorithm ∈ {shortest_path, max_throughput, min_hop}
RL (when enabled) action_type ∈ {discrete, continuous}; reward_type ∈ {throughput, mean_sinr}; step_size_m > 0 (discrete); arrival_threshold_m > 0 (continuous); x_min < x_max; y_min < y_max; controlled_node_id must match a node if set
Buildings Each building's x_min < x_max; y_min < y_max; z_min < z_max
