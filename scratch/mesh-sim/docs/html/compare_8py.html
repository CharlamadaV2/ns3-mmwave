Detailed Description

ECDF + bootstrap-CI comparison of pooled sim seeds vs ARPO field traces.

For each (scenario, link, metric) triple this module:

  1. Pools sim samples across all seed runs.
  2. Loads the matching field trace.
  3. Computes a two-sample K-S statistic and p-value.
  4. Renders an ECDF plot with a bootstrap confidence band around the sim curve.
  5. Writes per-scenario and aggregate metrics.csv / validation_summary.csv.

Also exports sim_to_field_scenario, the canonical name-mapping function used throughout the pipeline to translate sim scenario names to field names.
