Detailed Description

Minimal INI-file parser used by ConfigLoader.

Format rules

  • Comments: everything from the first # or ; to the end of the line is stripped before processing.
  • Section headers: [name] — the section name is trimmed of whitespace.
  • Key-value pairs: key=value — split on the first = sign; both key and value are trimmed of whitespace.
  • Lines without an = sign (and that are not section headers) are silently skipped.
  • Keys that appear before any [section] header are stored under the empty-string section key "".
