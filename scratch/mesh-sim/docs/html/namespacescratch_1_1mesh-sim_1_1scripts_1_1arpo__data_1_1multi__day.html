Compute Freedman-Diaconis histogram bin edges for pooled values.

The Freedman-Diaconis rule selects bin width as:

Bin width is proportional to the inter-quartile range, making it robust to outliers compared to Sturges or Scott's rule.

The resulting bin count is clamped to [min_bins, max_bins]. Falls back to a linear grid of min_bins bins when the IQR is zero or all values are identical.

Parameters
values1-D array of all pooled values across all days for one (link, metric) combination.
max_binsMaximum number of bins. Defaults to 80.
min_binsMinimum number of bins. Defaults to 20.
Returns
1-D array of n_bins + 1 bin edge values.

Render one normalised histogram overlay per day for a (family, link, metric) triple.

Produces one figure with one histogram bar chart and KDE curve per day, all normalised so each area integrates to 1. Days with different sample counts overlay directly. A dotted vertical line marks each day's median.

Bin edges are computed from all days' pooled values via _fd_bins so every day uses the same bin boundaries and bar heights are directly comparable. The KDE curve is evaluated on a 400-point grid via _kde_gaussian.

The subtitle reports:

  • With exactly two days: the median delta and the K-S statistic (ks_value).
  • With more than two days: the largest across all day pairs and the corresponding day pair.
Parameters
familyScenario family name for the figure title.
srcSource rab hostname.
peerPeer rab hostname.
metric_MetricSpec describing the metric being plotted.
bags_by_dayMapping from date string to _DayBag containing pooled values for that day.
ks_valuePre-computed K-S statistic to annotate in the subtitle, or None when there are more than two days.
Returns
Completed matplotlib Figure ready to be saved.

Run the full multi-day analysis and write all output files.

For each scenario family that has at least two days of data:

  1. Pool trace CSVs into _DayBag objects via _load_traces_for_family.
  2. Compute quantile summaries for _per_day_stats.csv.
  3. Compute K-S statistics for every day pair for _pairwise_ks.csv.
  4. Render and save an ECDF overlay PNG per (link, metric).
Parameters
per_day_rootDirectory of per-day plot output (produced by plot).
multi_day_rootOutput directory for multi-day results.
Returns
Tuple (per_day_rows, pairwise_rows) of the raw dicts written to CSV, useful for testing or downstream processing.
Exceptions
FileNotFoundErrorif per_day_root does not exist.
