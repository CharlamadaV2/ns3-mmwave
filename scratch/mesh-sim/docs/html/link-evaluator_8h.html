Detailed Description

Per-link path loss, SINR, and capacity computation.

LinkEvaluator wraps a pair of ns-3 propagation models — a PropagationLossModel and a ChannelConditionModel — and applies the configured TX power, beamforming gain, bandwidth, and noise figure to produce a complete LinkResult for each node pair.

Note
Configure must be called before Evaluate or EvaluateAll; calling either without first configuring produces undefined behaviour (null pointer dereference on the model pointers).
