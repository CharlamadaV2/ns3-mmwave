Detailed Description

Top-level simulation configuration and runtime metadata POD types.

SimConfig is the single root object that flows through the entire simulation. It is produced by ConfigLoader::Load, validated by ValidateConfig, and then passed by const-reference to every subsystem constructor. TimingInfo is intentionally separate from SimConfig because it is not loaded from any file — it is populated by sim.cc after the step loop completes and written to the output JSON by MetricsWriter.
