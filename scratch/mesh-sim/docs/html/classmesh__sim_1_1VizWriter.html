Detailed Description

Streams per-tick simulation state to six CSV files.

Holds a const reference to SimConfig (not a copy); the config must remain valid for the lifetime of the writer. The destructor calls Close so files are always flushed even if the step loop exits early.

Construct a writer for the given simulation configuration.

Computes m_vizTickS from cfg.viz_tick_ms and initialises m_nextWriteS to 0.0 so the very first tick is always written. Does not open any files; call Open before the step loop.

Append one snapshot to all six CSV files, rate-limited by viz_tick_ms.

Skips the write if time_s < m_nextWriteS (using a 1 ns epsilon for floating-point safety). When a write does occur, advances m_nextWriteS by m_vizTickS for the next boundary.

Internally calls the six private Write* helpers in order: positions → links → rx-power → mcs → flows → routes.

Parameters
time_sCurrent simulation time in seconds.
mobsMobility models for all nodes, in node-index order.
linksCurrent LinkTable from the link evaluator.
flowsFlow results from the routing engine for this tick.
