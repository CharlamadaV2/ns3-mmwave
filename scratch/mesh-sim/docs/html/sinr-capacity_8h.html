Detailed Description

SINR-to-capacity and SINR-to-MCS mapping functions.

amc_model Method
"shannon" Shannon-Hartley theorem: B·log₂(1+SNR). Theoretical upper
bound; real systems achieve roughly 60–80% of this value.
"table" 3GPP TS 38.214 NR CQI table (15 entries). Spectral efficiency
steps match the discrete MCS levels used by the field hardware.

The MCS table is derived from 3GPP TS 38.214 Table 5.1.3.1-1 and uses the same SINR thresholds and spectral efficiencies as MmWaveAmc::CreateCqiFeedbackWbTdma() in ns3-mmwave.
