Detailed Description

Run mesh-sim across a directory of scenarios, multi-seed.

Discovers all scenario subdirectories that contain a run.ini, invokes the ns-3 sim binary for each with a configurable set of random seeds, and writes outputs to a timestamped batch directory.

Optionally patches each scenario's nodes.json with real-GPS-derived waypoints before running (see build_waypoints).

Output layout
