Detailed Description

Root simulation configuration aggregating all subsystem parameters.

Produced by ConfigLoader::Load from run.ini and the JSON files it references. Validated by ValidateConfig before any ns-3 objects are constructed. Passed by const-reference to every subsystem constructor.

Timing parameters

  • tick_s must be ≤ duration_s.
  • warmup_s samples are excluded from all output metrics but the simulation still runs for the full duration_s.
  • viz_tick_ms controls how frequently CSV position/link snapshots are written; it is independent of tick_s.
