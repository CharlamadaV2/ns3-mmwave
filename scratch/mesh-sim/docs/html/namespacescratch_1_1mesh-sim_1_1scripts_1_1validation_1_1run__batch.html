◆ main()

int scratch.mesh-sim.scripts.validation.run_batch.main ( list[str] | None   argv = None)

CLI entry point for the batch runner.

Full workflow:

  1. Discover scenarios under --scenarios-dir.
  2. Locate the sim binary (auto-detect or --sim-binary).
  3. For each scenario (optionally filtered by --only):
    1. Optionally patch waypoints via patch_scenario_waypoints.
    2. Invoke the sim via _run_one.
    3. Append the result to batch_manifest.json (written after every run so a crash doesn't lose partial results).
  4. Print a final OK/failed count.
Parameters
argvArgument list; defaults to sys.argv[1:] when None.
Returns
0 if all scenarios succeeded, 1 if any failed.
