Detailed Description

Prints sim-time progress, wall-clock elapsed time, and ETA to stderr.

All fields must be set before the first call to Tick. The struct has no constructor — use aggregate initialisation or set fields directly.

void mesh_sim::ProgressLogger::Tick ( uint32_t  tick_index)
inline

Report progress if this tick falls on a reporting boundary.

Prints to stderr when tick_index is a multiple of interval_ticks or when tick_index equals total_ticks (ensuring the 100% line is always printed). All other ticks are a single modulo check and return immediately.

The ETA is estimated as:

rate = wall_elapsed / sim_elapsed (wall seconds per sim second)
eta_s = (duration_s - sim_t) * rate
