Detailed Description

Routing algorithm configuration.

The routing algorithm is applied once per tick to the current link-capacity graph produced by the link evaluator.

algorithm Strategy
"shortest_path" Dijkstra on the inverse-capacity-weighted graph (default).
"max_throughput" Widest-path: maximise the bottleneck link capacity.
"min_hop" Minimum hop count, ignoring link quality entirely.
