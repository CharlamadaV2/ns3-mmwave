Format a batch directory path as a compact two-line timestamp label.

Extracts the YYYY-MM/DD/HH-MM-SS components from the path and reformats them as HH:MM:SS\nYYYY-MM-DD for use as axis tick labels in heatmap figures. Falls back to the directory's basename if the path does not match the expected layout.

Parameters
batch_pathAbsolute or relative path string to a batch directory.
Returns
Two-line label such as "09:25:05\n2026-05-18".

Render a cross-batch heatmap PNG for one (metric, score) combination.

Rows are field scenarios, columns are batch directories. Each cell shows the mean of value_col across all links for that (scenario, batch) combination. Text colour flips from white to black at 50 % of the colour scale maximum for legibility on the viridis palette.

Parameters
dfCombined DataFrame of all batches' validation_summary.csv contents.
metricShort metric name to filter on (e.g. "snr").
value_colColumn to aggregate per cell (e.g. "abs_diff_medians").
value_labelHuman-readable label for the colour bar (e.g. "|Δmedian|").
out_pathDestination path for the PNG file.
Returns
True if the figure was written, False if no matching rows exist.

str scratch.mesh-sim.scripts.validation.compare_runs._scenario_label ( str  name)
private

Format a field scenario name as a compact two-line plot label.

Splits off the 8-digit date suffix and reformats it from MMDDYYYY to MM/DD/YYYY. The body has underscores replaced with spaces. Falls back to name unchanged if the trailing date cannot be parsed.

Parameters
nameField scenario name (e.g. "1-1_static_04172026").
Returns
Two-line string such as "1-1 static\n04/17/2026".
