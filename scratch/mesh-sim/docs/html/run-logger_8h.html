Detailed Description

Writes a human-readable run.log capturing seeds, CLI overrides, and the fully resolved configuration for reproducibility.

Call WriteRunLog once per batch run (not per seed) immediately after ResolveSeeds, before the per-seed simulation loop begins. The log captures the state of CliArgs and SimConfig at that point so that any subsequent seed run can be reproduced from the archived inputs alone.

Output: <base_output_dir>/run.log
