◆ ArchiveScenarioInputs()

void mesh_sim::ArchiveScenarioInputs ( const std::string &  base_output_dir,
const std::string &  run_config_path 
)

Copy all scenario input files into the batch output directory for reproducibility.

Creates <base_output_dir>/inputs/ and copies every regular file from the directory containing run_config_path (typically nodes.json, buildings.json, and run.ini itself). Subdirectories are not traversed. Existing files in the destination are silently overwritten.

This ensures every batch output directory is self-contained: re-running with the archived inputs produces identical results without needing the original scenario directory.

Parameters
base_output_dirRoot output directory for this batch run.
run_config_pathPath to run.ini; its parent directory is the source of files to archive.

Parse argv via ns3::CommandLine and return a populated CliArgs.

Registered flags:

Flag Type Required Description
–run-config string yes Path to run.ini.

–seed int no Single-seed override.

  • The run-config file does not exist on disk.
  • –positions-override is provided but the file does not exist.

◆ ResolveSeeds()

std::vector< uint32_t > mesh_sim::ResolveSeeds ( const CliArgs &  args,
const SimConfig &  cfg 
)

Determine the list of random seeds to run from CLI args and config defaults.

Resolution priority (highest to lowest):

  1. –seeds (comma-separated list) — parsed via parseSeedList().
  2. –seed (single integer override).
  3. cfg.seed (value from run.ini).

Exits with code 1 if the resolved list is empty (e.g. –seeds was supplied but contained no valid integers after parsing).

Parameters
argsParsed CLI arguments from ParseCommandLine.
cfgFully loaded simulation config from ConfigLoader::Load.
Returns
Non-empty vector of seed values in the order they should be run.
