using mesh_sim::IniMap = typedef std::map<std::string, std::map<std::string, std::string> >

Two-level string map produced by parseIni.

Indexed as ini[section][key]. The outer key is the section name (e.g. "scenario", "channel"). Keys that appear before any [section] header in the file are stored under the empty string "".

const std::string &  run_config_path

Copy all scenario input files into the batch output directory for reproducibility.

Creates <base_output_dir>/inputs/ and copies every regular file from the directory containing run_config_path (typically nodes.json, buildings.json, and run.ini itself). Subdirectories are not traversed. Existing files in the destination are silently overwritten.

This ensures every batch output directory is self-contained: re-running with the archived inputs produces identical results without needing the original scenario directory.

Parameters
base_output_dirRoot output directory for this batch run.
run_config_pathPath to run.ini; its parent directory is the source of files to archive.

◆ parseSeedList()

std::vector< uint32_t > mesh_sim::parseSeedList ( const std::string &  arg)

Parse a comma-separated string of seed values into a uint32_t vector.

Splits arg on ',' and converts each non-empty token with std::stoul. Empty tokens (e.g. the gap in "1,,3") are silently skipped so that trailing commas and double-commas are tolerated.

Note
On an invalid token (non-numeric or out of uint32_t range) this function prints an error to stderr and calls std::exit(1). It does not throw, matching the hard-exit convention used elsewhere in the CLI layer.
Parameters
argComma-separated seed string (e.g. "1,2,3,4,5").
Returns
Vector of parsed seed values in the order they appear in arg.

const std::string &  amc_model

Compute link capacity in Mbps from SINR and bandwidth.

Returns 0.0 for any SINR below SINR_MIN_DB, regardless of model.

Shannon model ("shannon") Applies the Shannon-Hartley theorem:

C = bandwidth_hz * log2(1 + 10^(sinr_db / 10)) [bits/s]

This is a theoretical upper bound. Real systems typically achieve 60–80% of the Shannon limit.

Table model ("table") Looks up the spectral efficiency for the highest supportable CQI index (via SinrToMcsIndex) and multiplies by bandwidth_hz:

C = MCS_TABLE[SinrToMcsIndex(sinr_db)].spectral_eff * bandwidth_hz

Write a human-readable reproducibility log for a batch run.

Creates <base_output_dir>/run.log (creating intermediate directories as needed). If the file cannot be opened the function returns silently; this is a best-effort log and should not abort the simulation.

Seed source label The log annotates which source provided the seed list:

  • "--seeds CLI argument" when args.seeds_arg is non-empty.
  • "--seed CLI override" when args.seed_override >= 0.
  • "config default" otherwise.
Parameters
base_output_dirBatch output root directory; run.log is written directly inside it (not per-seed).
argsParsed CLI arguments from ParseCommandLine.
cfgFully loaded SimConfig after ConfigLoader::Load. Only scalar fields are logged; node and building details are preserved in the archived nodes.json.
