Compute Freedman-Diaconis bin edges for pooled sim and field values.

The Freedman-Diaconis rule selects bin width as:

Making bin width proportional to the IQR produces robust binning when one distribution has heavy tails or outliers. The bin count is clamped to [min_bins, max_bins]. Falls back to a linear grid of min_bins bins when the IQR is zero or all values are identical.

Parameters
values1-D array of all pooled values (both sim and field combined).
max_binsMaximum number of bins. Defaults to 80.
min_binsMinimum number of bins. Defaults to 20.
Returns
1-D array of n_bins + 1 bin edge values.

Evaluate a Gaussian KDE on a grid using Silverman's bandwidth rule.

Pure numpy implementation — no scipy dependency. Subsamples values to at most max_samples points using a fixed RNG seed (0) for reproducibility when the O(n × m) kernel evaluation would be too slow.

Bandwidth uses Silverman's rule of thumb:

When the standard deviation is zero (all identical values), is clamped to 1.0 and the bandwidth floor is 1e-3 to prevent division by zero.

Parameters
values1-D array of observed values to estimate the density of.
x_grid1-D array of evaluation points.
max_samplesMaximum samples to use; larger inputs are randomly subsampled. Defaults to 20,000.
Returns
1-D array of density estimates at each point in x_grid. Returns an array of NaN if either input is empty.

Compute the two-sample Kolmogorov-Smirnov D-statistic without scipy.

Evaluates max |F_a(x) − F_b(x)| over the joint support by merging both sorted arrays and using binary search to evaluate each empirical CDF. Returns NaN when either input is empty.

The p-value is intentionally not returned: with sample sizes in the tens of thousands, p ≈ 0 even for operationally trivial distributional differences, making it uninformative for this use case.

Parameters
aFirst sample array (sim or field).
bSecond sample array (sim or field).
Returns
K-S D statistic in [0, 1]; NaN if either array is empty.

private

Run the full sim-vs-field comparison for one scenario directory.

  1. Resolves the field scenario name via sim_to_field_scenario.
  2. Discovers link pairs from the first seed's trace directory.
  3. For each (link, metric) pair: pools sim and field samples, computes K-S and summary stats, renders a histogram PNG, and appends a result row.
  4. Returns an empty list if the field directory is not found or no seeds exist.
Parameters
scenario_dirScenario directory containing a sim_traces/ subdirectory.
field_rootRoot of the field trace tree (see FIELD_TRACES_ROOT).
metricsList of _MetricSpec instances to evaluate.
out_dirOutput directory for per-link PNGs (validation/ subdir).
Returns
List of result dicts, one per (link, metric) combination.

Convert a sim scenario name to its corresponding field scenario name.

The two naming conventions differ in separator style and case:

  • Sim: arpo-1-1-static-04172026
  • Field: 1-1_static_04172026

This function is the single source of truth for that translation and is imported by build_waypoints and scenario_fidelity.
