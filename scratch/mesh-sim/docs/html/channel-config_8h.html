Detailed Description

Radio and channel configuration POD types.

Two channel models are supported, selected by ChannelConfig::channel_model:

  • "3gpp" — 3GPP TR 38.901 statistical model (default).
  • "nyu" — NYU WIRELESS mmWave model; requires the additional parameters in NyuChannelConfig.
