Detailed Description

Routing result for one flow at one simulation tick.

Produced by MeshRouter::Route and consumed by MetricsWriter, VizWriter, and the RL reward calculator.

Effective demand demand_mbps reflects the flow's effective demand this tick — it is zero when the flow is inactive or in the OFF phase of an on-off model, regardless of the configured per-flow demand. Only the on_off model sets in_on_phase to false; constant and Poisson flows always have demand_mbps equal to Flow::demand_mbps when active.

Unroutable flows When routable is false the path is empty, delivered_mbps is 0, latency_ms is 0, and hop_count is 0. The src and dst fields are always set.

Self-flows (src == dst) are marked routable = true with an empty path and zero delivered demand, since they require no forwarding.
