Detailed Description

Computes per-link radio metrics using ns-3 propagation models.

Stateless between calls (all per-call state lives in LinkResult). The ns-3 model pointers are set once by Configure and reused across every subsequent Evaluate / EvaluateAll call.

Bind ns-3 propagation models and extract scalar radio parameters.

Computes and caches:

  • Thermal noise floor: −174 + 10·log₁₀(bandwidth_Hz) + noise_figure_dB.
  • Combined beamforming gain: tx_array_gain_dBi + rx_array_gain_dBi.

Must be called once before Evaluate or EvaluateAll.

Evaluate one directed (tx → rx) link at the current node positions.

Co-location guard: if the 3-D distance between txMob and rxMob is less than 1 m, path loss is set to 0 dB and the full TX power plus beamforming gain is returned directly, bypassing the propagation model. This prevents undefined behaviour from log10(0) in distance-dependent models.

For all other distances:

  1. The channel condition model determines LOS vs. NLOS.
  2. The propagation loss model computes rx_power_dBm.
  3. Beamforming gain is added: rx_power += bf_gain_dB.
  4. SINR is computed against the thermal noise floor only (no ICI).
  5. SinrToCapacity and SinrToMcsIndex translate SINR to capacity and MCS index using the configured AMC model.
Parameters
txMobMobility model of the transmitting node.
rxMobMobility model of the receiving node.
txIdxIndex of the transmitter in SimConfig::nodes.
rxIdxIndex of the receiver in SimConfig::nodes.
Returns
Fully populated LinkResult for this directed pair.

Evaluate all N·(N−1)/2 unordered node pairs in index order.

Iterates pairs (i, j) with i < j, calling Evaluate for each. The returned vector is in the same order and has the same size as expected by LinkTable::Update.
