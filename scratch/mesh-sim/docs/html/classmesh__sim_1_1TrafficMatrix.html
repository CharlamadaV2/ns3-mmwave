Detailed Description

Generates and maintains the set of active flows each simulation tick.

Copies TrafficConfig and the node spec list at construction; does not hold a reference to SimConfig after the constructor returns.

Construct a traffic matrix from the simulation configuration.

Copies cfg.mesh.traffic, cfg.nodes, and cfg.tick_s. Creates two ns-3 RNG objects (UniformRandomVariable for Poisson generation / random pairs, ExponentialRandomVariable for on-off phase durations and Poisson holding times) and seeds them via the ns-3 global RngSeedManager.

const std::vector< Flow > & mesh_sim::TrafficMatrix::GetActiveFlows ( ) const

Return a const reference to the internal flow list.

Returns all flows — including inactive flows (in the OFF phase or expiring this tick) that have not yet been removed. MeshRouter filters by f.active and f.in_on_phase internally, so callers do not need to pre-filter.

The reference is valid until the next call to Tick or Initialize.

Create the initial set of flows for the configured topology.

Clears any existing flows, sets the node count, then calls the appropriate initialiser:

  • "all_pairs" → InitAllPairs
  • "random_pairs" → InitRandomPairs
  • "gateway" → InitGateway

Must be called once before the step loop, at currentTime = 0 for normal use (or at warmup end when pre-warming traffic state).

◆ Tick()

void mesh_sim::TrafficMatrix::Tick ( double  currentTime)

Advance the traffic state by one simulation tick.

Executed in three phases each tick:

  1. Expiry: any flow whose end_time_s > 0 and currentTime >= end_time_s is marked active = false.
  2. Model update: TickOnOff or TickPoisson is called for the respective model. The "constant" model requires no per-tick work.
  3. Removal: flows matching !active && end_time_s > 0 are erased from m_flows. Permanent flows (end_time_s == 0) are never removed.
Parameters
currentTimeCurrent simulation time in seconds.

◆ TickOnOff()

void mesh_sim::TrafficMatrix::TickOnOff ( double  currentTime)
private

Advance the ON/OFF state machine for all active flows.

For each active flow, checks whether phase_end_s <= currentTime. A while loop handles multiple phase transitions within a single tick (possible when tick_s is large relative to mean phase duration). Each transition: toggles in_on_phase and adds an exponential sample of the new phase's mean duration to phase_end_s.

Parameters
currentTimeCurrent simulation time (seconds).

◆ TickPoisson()

void mesh_sim::TrafficMatrix::TickPoisson ( double  currentTime)
private

Generate Poisson-distributed new flow arrivals for this tick.

Computes the expected arrivals: lambda = arrival_rate_hz × tick_s. The actual count is drawn using Knuth's product-of-uniforms method: multiply uniform(0,1) samples until their product falls below exp(-lambda); the count is the number of multiplications minus one.

Each new flow has a uniformly random src != dst (rejection sampling). When holding_time_s > 0, end_time_s is overridden with an independent Exponential(holding_time_s) draw so Poisson flows have exponentially distributed lifetimes rather than fixed ones.

Parameters
currentTimeCurrent simulation time (seconds).
