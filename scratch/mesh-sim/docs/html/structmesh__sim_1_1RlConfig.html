Detailed Description

Reinforcement-learning controller configuration.

When enabled is false every other field is ignored. When true the sim exchanges JSON observations and actions with an external RL agent via stdin/stdout at each tick (activated by the –rl-mode CLI flag).

Action types

action_type Description
"discrete" Left/right/up/down/stop offsets of step_size_m each tick.
"continuous" Absolute (x, y) velocity vector; capped by MaxSpeedForType.

Reward types

reward_type Description
"throughput" Sum of routed flow demand across all active paths.
"mean_sinr" Mean SINR in dB across all evaluated links.
