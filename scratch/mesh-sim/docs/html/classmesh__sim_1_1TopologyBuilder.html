Detailed Description

Translates a SimConfig into ns-3 mobility, building, and propagation model objects.

Holds a const reference to the SimConfig — the config must remain valid for the lifetime of the builder. All ns-3 smart pointers are retained internally after Build and returned by the accessor methods.

◆ Build()

void mesh_sim::TopologyBuilder::Build ( )

Create all ns-3 topology objects in the required order.

Executes three steps in sequence:

  1. CreateNodesAndMobility — one ns-3 node per NodeSpec, with the appropriate mobility model installed.
  2. CreateBuildings — ns-3 Building objects plus BuildingsHelper::Install; skipped when cfg.buildings is empty.
  3. ConfigurePropagationModel — selects and configures the 3GPP or NYU propagation loss model and the channel condition model.

Must be called exactly once, before any accessor method.

Exceptions
std::runtime_errorfor an unrecognised NodeSpec::mobility string, an unknown propagation scenario, or an unknown channel model string.

◆ ConfigurePropagationModel()

void mesh_sim::TopologyBuilder::ConfigurePropagationModel ( )
private

Select and configure the propagation and channel condition models.

Reads cfg.channel.channel_model ("3gpp" or "nyu") and cfg.channel.scenario to instantiate the correct ns-3 subclass. Sets the carrier frequency on the model. For NYU, also applies every field from NyuChannelConfig via SetAttribute.

Channel condition model:

  • Buildings present: BuildingsChannelConditionModel is installed on the propagation model and stored as m_conditionModel.
  • No buildings: the propagation model's default statistical condition model is retrieved and stored as m_conditionModel.
Exceptions
std::runtime_errorfor an unrecognised scenario or channel model string.

◆ CreateBuildings()

void mesh_sim::TopologyBuilder::CreateBuildings ( )
private

Create ns-3 Building objects from cfg.buildings.

A no-op when cfg.buildings is empty. For non-empty configs, creates one ns3::Building per BuildingSpec, sets its bounding box, type, exterior wall material, floor count, and room layout, then calls BuildingsHelper::Install(m_nodes) to associate all nodes with the building model. BuildingsHelper::Install must be called after all buildings are created and all nodes have mobility models installed.

void mesh_sim::TopologyBuilder::CreateNodesAndMobility ( )

Create one ns-3 node per NodeSpec and install its mobility model.

Iterates cfg.nodes in order, creates a single-node NodeContainer for each, dispatches to the appropriate InstallMobility* helper, and appends the resulting MobilityModel pointer to m_mobilityModels.

Exceptions
std::runtime_errorfor any unrecognised NodeSpec::mobility value.
