Detailed Description

Per-link radio evaluation result POD type.

One LinkResult is produced per ordered (tx, rx) node pair per simulation tick. The pair is directed: a LinkResult for (tx=0, rx=1) is independent of (tx=1, rx=0) because path loss, shadow fading, and blockage are evaluated separately for each direction.

Sentinel values rx_power_dbm and sinr_db are initialised to -999.0 dBm/dB to indicate "no valid measurement" (e.g. the link was not evaluated this tick, or the path loss exceeds the noise floor). Consumers should treat any value below a reasonable threshold (e.g. -200 dB) as invalid.
