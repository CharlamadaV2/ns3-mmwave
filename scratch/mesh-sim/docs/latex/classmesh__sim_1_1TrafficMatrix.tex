\doxysubsection{Detailed Description}
Generates and maintains the set of active flows each simulation tick. 

Copies \mbox{\hyperlink{structmesh__sim_1_1TrafficConfig}{Traffic\+Config}} and the node spec list at construction; does not hold a reference to \mbox{\hyperlink{structmesh__sim_1_1SimConfig}{Sim\+Config}} after the constructor returns.

Generate Poisson-\/distributed new flow arrivals for this tick. 

Computes the expected arrivals\+: {\ttfamily lambda} = arrival\+\_\+rate\+\_\+hz × tick\+\_\+s. The actual count is drawn using Knuth\textquotesingle{}s product-\/of-\/uniforms method\+: multiply uniform(0,1) samples until their product falls below {\ttfamily exp}(-\/lambda); the count is the number of multiplications minus one.

Each new flow has a uniformly random src != dst (rejection sampling). When {\ttfamily holding\+\_\+time\+\_\+s} $>$ 0, {\ttfamily end\+\_\+time\+\_\+s} is overridden with an independent {\ttfamily Exponential(holding\+\_\+time\+\_\+s)} draw so Poisson flows have exponentially distributed lifetimes rather than fixed ones.
