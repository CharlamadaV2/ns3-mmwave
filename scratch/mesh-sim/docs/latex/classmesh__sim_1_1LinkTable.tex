\doxysubsection{Detailed Description}
Symmetric N×N link-\/quality matrix, updated each simulation tick. 

Holds one \mbox{\hyperlink{structmesh__sim_1_1LinkResult}{Link\+Result}} per ordered node pair. Diagonal entries ({\ttfamily Get(i,i)}) return a default-\/constructed \mbox{\hyperlink{structmesh__sim_1_1LinkResult}{Link\+Result}} (all zeros / sentinels) and should not be used for routing or metrics.
