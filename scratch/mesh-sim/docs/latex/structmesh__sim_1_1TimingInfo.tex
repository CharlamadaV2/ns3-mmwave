\doxysubsection{Detailed Description}
Wall-\/clock timing metadata for one simulation run. 

Not loaded from any configuration file. Populated by {\ttfamily sim.\+cc} immediately before and after the main step loop, then passed to {\ttfamily \mbox{\hyperlink{classmesh__sim_1_1MetricsWriter}{Metrics\+Writer}}} which converts the {\ttfamily time\+\_\+point} values to ISO-\/8601 strings in the output JSON.
