\doxysubsection{Detailed Description}
Parsed command-\/line arguments for one simulator invocation. 

Populated by \mbox{\hyperlink{namespacemesh__sim_aa4b2ecd87a1d107fde936d7039ba25d3}{Parse\+Command\+Line}} and consumed by \mbox{\hyperlink{namespacemesh__sim_accda71be7646550a00f0f0492a9c93ed}{Resolve\+Seeds}} and the rest of {\ttfamily sim.\+cc}. String fields are empty when the corresponding flag was not supplied on the command line.
