\doxysubsection{Detailed Description}
Unzips ARPO data bundle into the configured extraction directory. 

The extractor skips OS-\/generated junk files (mac\+OS resource forks, Windows thumbnail caches, etc.) and is idempotent — re-\/running when the zip is older than the already-\/extracted tree is a no-\/op.

Extract the ARPO data bundle to the configured directory. 

The function is idempotent\+: if the extraction directory already exists and its mtime is newer than the zip, extraction is skipped and a summary of the existing CSVs is printed instead.

After extraction the directory\textquotesingle{}s mtime is updated so subsequent calls can detect that extraction is current.
