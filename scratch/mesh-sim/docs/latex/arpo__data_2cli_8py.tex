\doxysubsection{Detailed Description}
Main script to be ran for manipulating ARPO data as desired. 

Provides a command line interface that can do one of the following commands\+:
\begin{DoxyItemize}
\item Extract unzips data folder into extraction target direction
\item Multi-\/day compares day vs day data for multi day scenarios
\item Plot generates figures for specific scenario or all scenarios per individual day 
\end{DoxyItemize}
