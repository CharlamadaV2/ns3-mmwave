\hypertarget{md__home_kimson_ns3_mmwave_scratch_mesh_sim_src_io_README_autotoc_md37}{}\doxysection{Conventions}\label{md__home_kimson_ns3_mmwave_scratch_mesh_sim_src_io_README_autotoc_md37}

\begin{DoxyItemize}
\item {\bfseries{Two-\/phase pattern for {\ttfamily Metrics\+Writer}.}} {\ttfamily Accumulate\+Tick} is called every tick during the step loop; {\ttfamily Write} is called once after it completes. Calling {\ttfamily Write} before the loop ends produces a valid but incomplete summary.
\item {\bfseries{SINR sentinel filtering.}} {\ttfamily Accumulate\+Tick} only counts links with {\ttfamily sinr\+\_\+db $>$ −900.0}. Links at the −999.0 sentinel (unevaluated or below noise floor) are excluded from all SINR accumulators.
\item $\ast$$\ast${\ttfamily Progress\+Logger} and {\ttfamily Run\+Logger} are header-\/only.$\ast$$\ast$ They have no {\ttfamily .cc} file and no ns-\/3 dependency — they can be included anywhere without affecting build times.
