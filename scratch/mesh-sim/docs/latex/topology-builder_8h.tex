\doxysubsection{Detailed Description}
Creates ns-\/3 mobility models, buildings, and propagation models for the mesh topology. 

Topology\+Builder is the {\bfseries{only layer in mesh-\/sim that creates ns-\/3 objects}}. All other subsystems receive the resulting pointers via the accessor methods and operate entirely through the domain types defined in {\ttfamily src/domain/}. No EPC, RRC, MAC, or protocol stack is created.
