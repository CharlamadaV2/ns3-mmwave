\doxysubsection{Detailed Description}
MAC-\/address-\/to-\/rab-\/label resolution and stable per-\/node plot colours. 

{\bfseries{Vocabulary}}
\begin{DoxyItemize}
\item A {\itshape rab} is a chassis hostname ({\ttfamily rab1}, {\ttfamily rab2}, …).
\item Each rab carries several radios; each radio is one Linux netdev (e.\+g. {\ttfamily wl\+P1p1s0f0}) with its own MAC address.
\item {\ttfamily rab\+N.\+M} denotes rab N\textquotesingle{}s M-\/th netdev in alphabetical order, 1-\/based.
\end{DoxyItemize}

{\bfseries{Label resolution strategy}} Labels are built from the global union of {\ttfamily tag\+\_\+local\+\_\+mac} values across every scenario, so a peer MAC still resolves even when its owner\textquotesingle{}s {\ttfamily bh2.\+csv} is absent from the current scenario. Peer MACs that no rab ever claims are grouped by last-\/byte proximity and labelled {\ttfamily ext1}, {\ttfamily ext2}, …

{\bfseries{Granularity}} Resolution stops at the hostname level — no chassis sub-\/splitting.
