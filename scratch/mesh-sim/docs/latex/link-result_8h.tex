\doxysubsection{Detailed Description}
Per-\/link radio evaluation result POD type. 

One Link\+Result is produced per ordered (tx, rx) node pair per simulation tick. The pair is {\itshape directed}\+: a {\ttfamily Link\+Result} for (tx=0, rx=1) is independent of (tx=1, rx=0) because path loss, shadow fading, and blockage are evaluated separately for each direction.

{\bfseries{Sentinel values}} {\ttfamily rx\+\_\+power\+\_\+dbm} and {\ttfamily sinr\+\_\+db} are initialised to {\ttfamily -\/999.\+0} d\+Bm/dB to indicate \char`\"{}no valid measurement\char`\"{} (e.\+g. the link was not evaluated this tick, or the path loss exceeds the noise floor). Consumers should treat any value below a reasonable threshold (e.\+g. -\/200 dB) as invalid.
