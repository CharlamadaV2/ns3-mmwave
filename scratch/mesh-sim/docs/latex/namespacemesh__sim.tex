Copy all scenario input files into the batch output directory for reproducibility. 

Creates {\ttfamily } $<$base\+\_\+output\+\_\+dir$>$/inputs/ and copies every regular file from the directory containing {\ttfamily run\+\_\+config\+\_\+path} (typically {\ttfamily nodes.\+json}, {\ttfamily buildings.\+json}, and {\ttfamily run.\+ini} itself). Subdirectories are not traversed. Existing files in the destination are silently overwritten.

This ensures every batch output directory is self-\/contained\+: re-\/running with the archived inputs produces identical results without needing the original scenario directory.
