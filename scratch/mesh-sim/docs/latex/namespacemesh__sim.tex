\doxysubsection{Detailed Description}
\mbox{\hyperlink{classmesh__sim_1_1ConfigLoader}{Config\+Loader}}\+: parses run.\+ini + referenced nodes.\+json / buildings.\+json and returns a fully populated \mbox{\hyperlink{structmesh__sim_1_1SimConfig}{Sim\+Config}} struct. 

\mbox{\hyperlink{classmesh__sim_1_1TopologyBuilder}{Topology\+Builder}}\+: creates ns-\/3 mobility models, buildings, and propagation models for the mesh topology. This is the only layer that creates ns-\/3 objects. No EPC, RRC, MAC, or protocol stack.

\mbox{\hyperlink{classmesh__sim_1_1MeshRouter}{Mesh\+Router}}\+: routes flows over the mesh link graph. Supports Dijkstra shortest-\/path, widest-\/path (max throughput), and min-\/hop (BFS) algorithms. Applies proportional-\/fairness congestion scaling when links are overloaded.

\mbox{\hyperlink{classmesh__sim_1_1VizWriter}{Viz\+Writer}}\+: writes per-\/tick CSV snapshots for GUI and plotting consumption. Called from the step loop at viz\+\_\+tick\+\_\+ms intervals.

Run\+Logger\+: writes a run.\+log capturing seeds, CLI overrides, and resolved config for reproducibility. Header-\/only (same pattern as \mbox{\hyperlink{progress-logger_8h_source}{progress-\/logger.\+h}}). No ns-\/3 dependency.

\mbox{\hyperlink{structmesh__sim_1_1ProgressLogger}{Progress\+Logger}}\+: prints simulation progress to stderr. Called directly from the step loop (no Simulator\+::\+Schedule). Header-\/only.

\mbox{\hyperlink{classmesh__sim_1_1MetricsWriter}{Metrics\+Writer}}\+: accumulates per-\/tick metrics in-\/memory during the step loop, then writes summary.\+json after the simulation completes.

SINR-\/to-\/capacity mapping functions. Pure math, no ns-\/3 dependency. Used by \mbox{\hyperlink{classmesh__sim_1_1LinkEvaluator}{Link\+Evaluator}} and testable standalone.

\mbox{\hyperlink{classmesh__sim_1_1LinkTable}{Link\+Table}}\+: NxN link quality matrix updated each tick. Wraps the flat output of Link\+Evaluator\+::\+Evaluate\+All() into a symmetric matrix with O(1) per-\/link lookup.

\mbox{\hyperlink{classmesh__sim_1_1LinkEvaluator}{Link\+Evaluator}}\+: wraps ns-\/3 propagation models to compute per-\/link path loss, SINR, and capacity. Core physics engine of mesh-\/sim.

Top-\/level simulation configuration and runtime metadata POD types. No ns-\/3 headers included — keeps compilation fast and allows use in post-\/run IO code without ns-\/3 linkage.

Mesh-\/specific configuration POD types\+: traffic generation and routing. No ns-\/3 headers included.

Per-\/link evaluation result POD type. One instance per ordered pair (tx, rx) per time step. No ns-\/3 headers included.

Config validation\+: checks a fully-\/loaded \mbox{\hyperlink{structmesh__sim_1_1SimConfig}{Sim\+Config}} for invalid or inconsistent values before the simulation runs. No ns-\/3 headers -- can be tested independently.

Command-\/line parsing and pre-\/simulation setup helpers. Keeps sim.\+cc focused on orchestration.

No ns-\/3 headers included — this code can be compiled and tested independently of the ns-\/3 build.

No ns-\/3 headers -- stdlib and nlohmann/json only.

Output files\+: positions.\+csv -- time\+\_\+s, node\+\_\+id, x, y, z, node\+\_\+type, active links.\+csv -- time\+\_\+s, node\+\_\+a, node\+\_\+b, dist\+\_\+m, sinr\+\_\+db, condition, condition\+\_\+reason, capacity\+\_\+mbps, delivered\+\_\+mbps, hop\+\_\+count rx-\/power.\+csv -- time\+\_\+s, node\+\_\+a, node\+\_\+b, rx\+\_\+power\+\_\+dbm mcs.\+csv -- time\+\_\+s, node\+\_\+a, node\+\_\+b, mcs\+\_\+index, spectral\+\_\+eff flows.\+csv -- time\+\_\+s, src, dst, demand\+\_\+mbps, delivered\+\_\+mbps, latency\+\_\+ms, hop\+\_\+count, routable routes.\+csv -- time\+\_\+s, src, dst, path, bottleneck\+\_\+mbps, hop\+\_\+count, routable
