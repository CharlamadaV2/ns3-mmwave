\doxysubsection{Detailed Description}
Full specification for one simulation node. 

Loaded from the {\ttfamily nodes} array in {\ttfamily nodes.\+json}. The active mobility model is selected by {\ttfamily mobility}; only the corresponding parameter struct ({\ttfamily velocity}, {\ttfamily random\+\_\+walk}, or {\ttfamily waypoints}) is used at runtime.
