{\ttfamily multiday\+\_\+variance} is a read-\/only summary over the CSV produced by {\ttfamily multi-\/day}. It prints three views — per-\/family rollup, per-\/link rollup, and the detail table sorted by {\ttfamily $\vert$Δmed$\vert$} descending — so unstable day-\/to-\/day links surface at the top without opening any PNGs.
