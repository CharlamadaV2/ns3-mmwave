\doxysubsection{Detailed Description}
A single directed traffic flow between two nodes. 

Flows are created by \mbox{\hyperlink{classmesh__sim_1_1TrafficMatrix}{Traffic\+Matrix}} and consumed by \mbox{\hyperlink{classmesh__sim_1_1MeshRouter}{Mesh\+Router}}. The on-\/off model state ({\ttfamily in\+\_\+on\+\_\+phase}, {\ttfamily phase\+\_\+end\+\_\+s}) is only meaningful when the traffic model is {\ttfamily \char`\"{}on\+\_\+off\char`\"{}}; for other models these fields retain their default values and are ignored by the router.
