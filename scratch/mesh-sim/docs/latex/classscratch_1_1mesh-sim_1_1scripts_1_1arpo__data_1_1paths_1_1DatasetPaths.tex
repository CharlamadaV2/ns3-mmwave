\doxysubsection{Detailed Description}
Scenario names whose CSVs are known to be contaminated or partial. 

For example, the collection process crashed mid-\/run and wrote malformed JSONL. These are silently skipped during multi-\/day aggregation.

Locations and filename conventions for one ARPO-\/style dataset.

Frozen so it can be used as a dict key or placed in a set. Construct a custom instance to point at a different zip/extract tree without touching any module-\/level state.
