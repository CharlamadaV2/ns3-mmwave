\doxysubsection{Detailed Description}
Complete radio and channel configuration for a simulation run. 

Parameters shared between the 3GPP and NYU models are at the top level. NYU-\/specific parameters live in the \mbox{\hyperlink{structmesh__sim_1_1ChannelConfig_a5827b36e2126974b2967c52654597201}{nyu}} sub-\/struct.

Gain values ({\ttfamily tx\+\_\+array\+\_\+gain\+\_\+dbi}, {\ttfamily rx\+\_\+array\+\_\+gain\+\_\+dbi}) represent peak directional beamforming gain per side and are applied symmetrically; each node uses the same antenna model.
