Compute Freedman-\/\+Diaconis bin edges for pooled sim and field values. 

The Freedman-\/\+Diaconis rule selects bin width as\+: \[ w = 2 \cdot \mathrm{IQR}(x) \cdot n^{-1/3} \] Making bin width proportional to the IQR produces robust binning when one distribution has heavy tails or outliers. Evaluate a Gaussian KDE on a grid using Silverman\textquotesingle{}s bandwidth rule. 

Pure numpy implementation — no scipy dependency. Subsamples {\ttfamily values} to at most {\ttfamily max\+\_\+samples} points using a fixed RNG seed (0) for reproducibility when the O(n × m) kernel evaluation would be too slow.

Bandwidth uses Silverman\textquotesingle{}s rule of thumb\+: \[ h = 1.06 \hat\sigma n^{-1/5} \] When the standard deviation is zero (all identical values), $ \sigma $ is clamped to 1.\+0 and the bandwidth floor is 1e-\/3 to prevent division by zero.

Compute the two-\/sample Kolmogorov-\/\+Smirnov D-\/statistic without scipy. 

Evaluates {\ttfamily max $\vert$\+F\+\_\+a(x) − F\+\_\+b(x)$\vert$} over the joint support by merging both sorted arrays and using binary search to evaluate each empirical CDF. Returns NaN when either input is empty.
