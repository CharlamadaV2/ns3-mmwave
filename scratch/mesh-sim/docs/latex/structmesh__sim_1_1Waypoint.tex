\doxysubsection{Detailed Description}
A single timed waypoint in a node\textquotesingle{}s mobility trajectory. 

Waypoints are stored in time order in \mbox{\hyperlink{structmesh__sim_1_1NodeSpec_a80786d2b403d20b06661059d28341476}{Node\+Spec\+::waypoints}}. The simulator linearly interpolates position between consecutive waypoints.
