\doxysubsection{Detailed Description}
Per-\/link path loss, SINR, and capacity computation. 

Link\+Evaluator wraps a pair of ns-\/3 propagation models — a {\ttfamily Propagation\+Loss\+Model} and a {\ttfamily Channel\+Condition\+Model} — and applies the configured TX power, beamforming gain, bandwidth, and noise figure to produce a complete Link\+Result for each node pair.

\begin{DoxyNote}{Note}
Configure must be called before Evaluate or Evaluate\+All; calling either without first configuring produces undefined behaviour (null pointer dereference on the model pointers). 
\end{DoxyNote}
