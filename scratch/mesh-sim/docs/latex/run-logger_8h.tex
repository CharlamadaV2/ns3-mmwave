\doxysubsection{Detailed Description}
Writes a human-\/readable run.\+log capturing seeds, CLI overrides, and the fully resolved configuration for reproducibility. 

Call Write\+Run\+Log once per batch run (not per seed) immediately after Resolve\+Seeds, before the per-\/seed simulation loop begins. The log captures the state of Cli\+Args and Sim\+Config at that point so that any subsequent seed run can be reproduced from the archived inputs alone.
