\doxysubsection{Detailed Description}
Result of a \mbox{\hyperlink{namespacemesh__sim_a09050ff52e549176ef6ec6f11b137eea}{Validate\+Config}} call. 

On success {\ttfamily errors} is empty and \mbox{\hyperlink{structmesh__sim_1_1ValidationResult_a68d91f6b81fc7cf63bba5bf9dfbaf96c}{ok}} returns {\ttfamily true}. On failure {\ttfamily errors} contains one human-\/readable string per problem found; all problems are reported together so the user can fix them in one pass.
