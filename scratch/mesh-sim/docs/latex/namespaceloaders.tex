\doxysubsection{Detailed Description}
Per-\/scenario CSV loaders for backhaul-\/radio and GPS data. 

{\bfseries{Clock skew handling}} Node clocks drift relative to each other, so raw timestamps are not directly comparable across nodes. All loaders add a {\ttfamily \+\_\+\+\_\+sec\+\_\+\+\_\+} column containing seconds since each {\itshape session\textquotesingle{}s} first sample, making cross-\/session time axes directly comparable.
