\hypertarget{md__home_kimson_ns3_mmwave_scratch_mesh_sim_scripts_validation_README_autotoc_md12}{}\doxysection{Conventions}\label{md__home_kimson_ns3_mmwave_scratch_mesh_sim_scripts_validation_README_autotoc_md12}

\begin{DoxyItemize}
\item {\bfseries{Distributional comparison, not temporal.}} Sim and field samples are pooled raw (no smoothing, no time alignment). The comparison is over the marginal distribution of each metric.
\item {\bfseries{MCS cap.}} Sim MCS is post-\/capped at 12 to match the field firmware limit before any comparison is made.
\item {\bfseries{Sim trace MAC columns are empty.}} {\ttfamily sim\+\_\+to\+\_\+traces} leaves {\ttfamily tag\+\_\+local\+\_\+mac}, {\ttfamily tag\+\_\+sta\+\_\+mac}, and {\ttfamily tag\+\_\+interface} blank — the sim has no per-\/antenna identity.
\item {\bfseries{Scenario name mapping.}} Sim names translate to field names by stripping {\ttfamily arpo-\/}, joining the middle tokens with {\ttfamily \+\_\+}, and upper-\/casing single-\/letter family tokens\+: {\ttfamily arpo-\/1-\/x-\/misc-\/04172026} → {\ttfamily 1-\/X\+\_\+misc\+\_\+04172026}.
\item {\bfseries{NaN rows in {\ttfamily validation\+\_\+summary.\+csv}}} mean the field collect did not capture telemetry for that link (e.\+g. rab2 and rab3 were not beam-\/paired during the scenario). This is expected for some scenarios and is not a pipeline error.
\item $\ast$$\ast${\ttfamily -\/-\/auto-\/waypoints} mutates {\ttfamily inputs/}.$\ast$$\ast$ The patch is permanent for the duration of the run. Use {\ttfamily git diff inputs/} to review and {\ttfamily git checkout inputs/} to revert.
\item $\ast$$\ast${\ttfamily build\+\_\+waypoints} mobility classifier is bbox-\/based$\ast$$\ast$ (threshold\+: 20 m max bounding-\/box dimension). Path length alone is GPS-\/noise-\/prone and would misclassify jittery static nodes as mobile.
\end{DoxyItemize}\hypertarget{md__home_kimson_ns3_mmwave_scratch_mesh_sim_scripts_validation_README_autotoc_md13}{}\doxysection{Dependencies}\label{md__home_kimson_ns3_mmwave_scratch_mesh_sim_scripts_validation_README_autotoc_md13}
