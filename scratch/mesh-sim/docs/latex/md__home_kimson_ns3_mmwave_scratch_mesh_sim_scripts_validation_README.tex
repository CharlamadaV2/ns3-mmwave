{\ttfamily -\/-\/auto-\/waypoints} on {\ttfamily \mbox{\hyperlink{namespacerun__batch}{run\+\_\+batch}}} patches each scenario\textquotesingle{}s {\ttfamily nodes.\+json} in-\/place from its field GPS trace before invoking the sim (skips static-\/rab2 scenarios automatically). The patch is permanent — {\ttfamily git diff inputs/} to see what changed, {\ttfamily git checkout inputs/} to revert.

{\ttfamily \mbox{\hyperlink{namespacebuild__waypoints}{build\+\_\+waypoints}}} reads the field {\ttfamily gps\+\_\+track\+\_\+trace.\+csv} for a scenario, translates to the sim frame using a stationary anchor node (default {\ttfamily rab1}), downsamples the moving node\textquotesingle{}s track to N waypoints, and patches them into the scenario\textquotesingle{}s {\ttfamily nodes.\+json} with {\ttfamily mobility = \char`\"{}waypoint\char`\"{}}. Time modes\+: {\ttfamily raw} (use field clock as-\/is), {\ttfamily clip} (cap at {\ttfamily -\/-\/duration}), {\ttfamily scale} (stretch/compress to {\ttfamily -\/-\/duration}). After patching, rebuild the sim and re-\/run.

{\ttfamily \mbox{\hyperlink{namespacescenario__fidelity}{scenario\+\_\+fidelity}}} reads each scenario\textquotesingle{}s snapshotted {\ttfamily nodes.\+json} + {\ttfamily seed-\/1/positions.\+csv} and the field\textquotesingle{}s {\ttfamily gps\+\_\+track\+\_\+trace.\+csv} (produced by {\ttfamily arpo\+\_\+data.\+cli plot}), then for each rab reports field-\/vs-\/sim bounding box, path length, and mobility class (static / mobile), plus pairwise t=0 distances between rabs. It surfaces mismatches like \char`\"{}rab2 drives a 1.\+7 km loop in the field but the sim has it pinned \`{}fixed\`{}.\char`\"{} The mobility classifier is bbox-\/based (threshold 20 m max-\/dim) so cumulative GPS jitter doesn\textquotesingle{}t trip it.

{\ttfamily \mbox{\hyperlink{namespacecompare__runs}{compare\+\_\+runs}}} auto-\/discovers every batch under {\ttfamily outputs/} with a {\ttfamily validation\+\_\+summary.\+csv}, or accepts explicit batch dirs as positional args. It prints the headline summary (channel/gain/tx config + mean $\vert$Δmed$\vert$ + mean K-\/S per batch), the close vs far link-\/class breakdown, and a per-\/scenario matrix so you can see which scenarios drive the mean. \hypertarget{md__home_kimson_ns3_mmwave_scratch_mesh_sim_scripts_validation_README_autotoc_md11}{}\doxysection{Conventions}\label{md__home_kimson_ns3_mmwave_scratch_mesh_sim_scripts_validation_README_autotoc_md11}

\begin{DoxyItemize}
\item Sim and field samples are pooled raw (no smoothing, no time alignment) -- the comparison is distributional, not temporal.
\item Sim MCS is post-\/capped at 12 to match the field firmware limit.
\item Sim trace CSVs leave {\ttfamily tag\+\_\+local\+\_\+mac} / {\ttfamily tag\+\_\+sta\+\_\+mac} / {\ttfamily tag\+\_\+interface} empty (sim has no per-\/antenna identity).
\item Scenario names map by stripping {\ttfamily arpo-\/}, joining the middle tokens with {\ttfamily \+\_\+}, and upper-\/casing single-\/letter family tokens ({\ttfamily arpo-\/1-\/x-\/misc-\/04172026} → {\ttfamily 1-\/X\+\_\+misc\+\_\+04172026}).
\item {\ttfamily NaN} rows in {\ttfamily validation\+\_\+summary.\+csv} mean the field collect didn\textquotesingle{}t capture telemetry for that link (e.\+g. rab2 and rab3 weren\textquotesingle{}t beam-\/paired in {\ttfamily 2-\/7\+\_\+throughput\+\_\+stationary} or {\ttfamily 2-\/X\+\_\+blocking}). Not a pipeline bug -- there is nothing to compare against.
