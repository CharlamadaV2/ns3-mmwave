\doxysubsection{Detailed Description}
Topology and geometry POD types\+: nodes, buildings, and spatial properties. 

{\bfseries{Coordinate convention}} All positions are stored as (x, y, z) triples in metres.
\begin{DoxyItemize}
\item 2-\/D scenarios\+: set z to a constant height for all nodes.
\item 1-\/D scenarios\+: additionally set y = 0 for all nodes. The coordinate system is arbitrary; only relative geometry matters. 
\end{DoxyItemize}
