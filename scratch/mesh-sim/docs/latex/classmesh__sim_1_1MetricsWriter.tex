\doxysubsection{Detailed Description}
Accumulates per-\/tick radio and flow metrics, then writes summary.\+json. 

All accumulation is done in-\/memory; the file is written exactly once by \mbox{\hyperlink{classmesh__sim_1_1MetricsWriter_a62a9a193e9c6f182491282265f62f1e0}{Write}} after the step loop completes.

Accumulate metrics for one simulation tick. 

Ticks with {\ttfamily time\+\_\+s} $<$ {\ttfamily cfg.\+warmup\+\_\+s} are silently skipped so that transient start-\/up behaviour is excluded from all averages.

For each node pair the SINR sentinel value (−999.0 d\+Bm) is filtered\+: only links with {\ttfamily sinr\+\_\+db} $>$ −900.0 contribute to SINR accumulators, preventing unevaluated links from corrupting the statistics.

Write all accumulated metrics to {\ttfamily } $<$output\+\_\+dir$>$/summary.json. 

All per-\/node and per-\/flow values are time-\/averaged over the number of post-\/warmup ticks in which they were observed. Node IDs from {\ttfamily cfg.\+nodes} are used as JSON keys; unrecognised indices fall back to {\ttfamily \char`\"{}node$<$idx$>$\char`\"{}}.

Prints an error to {\ttfamily stderr} if the file cannot be opened; does not throw.
