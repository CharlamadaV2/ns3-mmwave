Report (rab, netdev) keys whose MAC address is claimed by more than one device. 

Calls \mbox{\hyperlink{namespacescratch_1_1mesh-sim_1_1scripts_1_1arpo__data_1_1topology__audit_afb024ca5f1eaf3b7dd825c83e7409b48}{\+\_\+scan}} to build the full (rab, mac, netdev, device\+\_\+name, host) inventory and \mbox{\hyperlink{namespacescratch_1_1mesh-sim_1_1scripts_1_1arpo__data_1_1topology__audit_a9d1c5583c1d0289da4e87eb07ab6f12e}{\+\_\+peer\+\_\+counts}} to annotate activity levels.
