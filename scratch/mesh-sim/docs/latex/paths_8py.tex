\doxysubsection{Detailed Description}
Filesystem locations and per-\/file conventions for ARPO-\/style datasets. 

Defaults target the bundled Spring Lake zip under {\ttfamily data/}. Callers that analyse a different bundle should construct their own Dataset\+Paths instead of relying on the module-\/level aliases at the bottom of this file.
