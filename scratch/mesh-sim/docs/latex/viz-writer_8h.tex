\doxysubsection{Detailed Description}
Writes per-\/tick CSV snapshots for GUI and offline plotting. 

Viz\+Writer maintains six open CSV files for the duration of the simulation and appends one row (or one row per node/link/flow) each time Write\+Tick is called. Writes are rate-\/limited to {\ttfamily viz\+\_\+tick\+\_\+ms} intervals so a small tick step ({\ttfamily tick\+\_\+s}) does not inflate file sizes unnecessarily.
