Compute Freedman-\/\+Diaconis histogram bin edges for pooled values. 

The Freedman-\/\+Diaconis rule selects bin width as\+: \[ w = 2 \cdot \mathrm{IQR}(x) \cdot n^{-1/3} \] Bin width is proportional to the inter-\/quartile range, making it robust to outliers compared to Sturges or Scott\textquotesingle{}s rule.

The resulting bin count is clamped to \mbox{[}{\ttfamily min\+\_\+bins}, {\ttfamily max\+\_\+bins}\mbox{]}. Falls back to a linear grid of {\ttfamily min\+\_\+bins} bins when the IQR is zero or all values are identical.

Evaluate a Gaussian KDE on a grid using Silverman\textquotesingle{}s bandwidth rule. 

Pure numpy implementation — no scipy dependency. Subsamples {\ttfamily values} to at most {\ttfamily max\+\_\+samples} points using a fixed RNG seed (0) for reproducibility when the sample count would make the O(n × m) kernel evaluation slow.

Bandwidth uses Silverman\textquotesingle{}s rule of thumb\+: \[ h = 1.06 \hat\sigma n^{-1/5} \] where $ \hat\sigma $ is the sample standard deviation. When the standard deviation is zero (all identical values), $ \sigma $ is clamped to 1.\+0 to prevent a degenerate zero bandwidth.

Render one normalised histogram overlay per day for a (family, link, metric) triple. 

Produces one figure with one histogram bar chart and KDE curve per day, all normalised so each area integrates to 1. Days with different sample counts overlay directly. A dotted vertical line marks each day\textquotesingle{}s median.

Bin edges are computed from all days\textquotesingle{} pooled values via \mbox{\hyperlink{namespacescratch_1_1mesh-sim_1_1scripts_1_1arpo__data_1_1multi__day_a8fda8522f33b95a2e1ae491df34b128b}{\+\_\+fd\+\_\+bins}} so every day uses the same bin boundaries and bar heights are directly comparable. The KDE curve is evaluated on a 400-\/point grid via \mbox{\hyperlink{namespacescratch_1_1mesh-sim_1_1scripts_1_1arpo__data_1_1multi__day_a8ecc23bae2f12675d17748eb9667f187}{\+\_\+kde\+\_\+gaussian}}.

The subtitle reports\+:
\begin{DoxyItemize}
\item With exactly two days\+: the median delta and the K-\/S statistic ({\ttfamily ks\+\_\+value}).
\item With more than two days\+: the largest $ |\Delta\mathrm{med}| $ across all day pairs and the corresponding day pair.
