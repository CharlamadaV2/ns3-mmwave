\doxysubsection{Detailed Description}
Streams per-\/tick simulation state to six CSV files. 

Holds a const reference to \mbox{\hyperlink{structmesh__sim_1_1SimConfig}{Sim\+Config}} (not a copy); the config must remain valid for the lifetime of the writer. The destructor calls \mbox{\hyperlink{classmesh__sim_1_1VizWriter_a481338af7473f3c9309a02981bbfd5e1}{Close}} so files are always flushed even if the step loop exits early.

Append one snapshot to all six CSV files, rate-\/limited by {\ttfamily viz\+\_\+tick\+\_\+ms}. 

Skips the write if {\ttfamily time\+\_\+s} $<$ {\ttfamily m\+\_\+next\+WriteS} (using a 1 ns epsilon for floating-\/point safety). When a write does occur, advances {\ttfamily m\+\_\+next\+WriteS} by {\ttfamily m\+\_\+viz\+TickS} for the next boundary.

Internally calls the six private {\ttfamily Write$\ast$} helpers in order\+: positions → links → rx-\/power → mcs → flows → routes.
