\doxysubsection{Detailed Description}
Lightweight simulation progress reporter. 

Progress\+Logger is called directly from the step loop — not via {\ttfamily ns3\+::\+Simulator\+::\+Schedule} — so it has zero overhead on non-\/reporting ticks (a single modulo check per tick).
