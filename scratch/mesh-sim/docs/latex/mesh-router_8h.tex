\doxysubsection{Detailed Description}
Flow-\/level routing over the mesh link graph. 

Mesh\+Router takes the current Link\+Table and a list of active Flow objects, finds a path for each flow using the configured algorithm, then applies proportional-\/fairness congestion scaling to produce a Flow\+Result for every flow.
