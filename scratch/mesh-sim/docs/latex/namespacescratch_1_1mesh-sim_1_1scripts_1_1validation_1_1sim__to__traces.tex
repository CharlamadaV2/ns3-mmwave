Convert one sim metric CSV into a normalised per-\/link Data\+Frame. 

Steps performed\+:
\begin{DoxyEnumerate}
\item Guard against missing files or columns.
\item Drop rows before {\ttfamily warmup\+\_\+s}.
\item Map integer node IDs to rab labels; drop rows with unknown IDs.
\item Reindex columns to match the trace CSV schema.
\end{DoxyEnumerate}

The output Data\+Frame always has columns\+: {\ttfamily sec}, {\ttfamily source}, {\ttfamily peer}, {\ttfamily tag\+\_\+local\+\_\+mac}, {\ttfamily tag\+\_\+sta\+\_\+mac}, {\ttfamily tag\+\_\+interface}, {\ttfamily $<$trace\+\_\+column$>$}. The MAC/interface columns are empty strings because sim output has no hardware-\/level identifiers; downstream tools handle their absence gracefully.
