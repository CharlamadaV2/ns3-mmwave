\doxysubsection{Detailed Description}
Flow-\/level traffic demand generation for the mesh. 

Traffic\+Matrix maintains a list of Flow objects and updates them each tick according to the configured traffic model. There are no packets — a flow simply represents \char`\"{}node A wants X Mbps to node B.\char`\"{}

{\bfseries{Flow removal}} Expired flows ({\ttfamily end\+\_\+time\+\_\+s} $>$ 0 and {\ttfamily active} == false) are erased from {\ttfamily m\+\_\+flows} each tick. Permanent flows ({\ttfamily end\+\_\+time\+\_\+s} == 0) are never removed, even when they transition to inactive in the on-\/off model.

{\bfseries{Gateway resolution}} For the {\ttfamily \char`\"{}gateway\char`\"{}} topology, Traffic\+Config\+::gateway\+\_\+node\+\_\+id is resolved as a numeric index first ({\ttfamily stoul}); if that throws, it falls back to a linear search by Node\+Spec\+::id string. Index 0 is used when {\ttfamily gateway\+\_\+node\+\_\+id} is empty.
