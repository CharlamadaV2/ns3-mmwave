\doxysubsection{Detailed Description}
Computes per-\/link radio metrics using ns-\/3 propagation models. 

Stateless between calls (all per-\/call state lives in \mbox{\hyperlink{structmesh__sim_1_1LinkResult}{Link\+Result}}). The ns-\/3 model pointers are set once by \mbox{\hyperlink{classmesh__sim_1_1LinkEvaluator_a5e0af315989e135767eb4878d08ac61c}{Configure}} and reused across every subsequent \mbox{\hyperlink{classmesh__sim_1_1LinkEvaluator_a132e1068c43059b44087db448606c900}{Evaluate}} / \mbox{\hyperlink{classmesh__sim_1_1LinkEvaluator_a16c39016432fb10dc7358821d4ab3cac}{Evaluate\+All}} call.

Evaluate one directed (tx → rx) link at the current node positions. 

{\bfseries{Co-\/location guard}}\+: if the 3-\/D distance between {\ttfamily tx\+Mob} and {\ttfamily rx\+Mob} is less than 1 m, path loss is set to 0 dB and the full TX power plus beamforming gain is returned directly, bypassing the propagation model. This prevents undefined behaviour from {\ttfamily log10(0)} in distance-\/dependent models.

For all other distances\+:
\begin{DoxyEnumerate}
\item The channel condition model determines LOS vs. NLOS.
\item The propagation loss model computes {\ttfamily rx\+\_\+power\+\_\+d\+Bm}.
\item Beamforming gain is added\+: {\ttfamily rx\+\_\+power} += bf\+\_\+gain\+\_\+dB.
\item SINR is computed against the thermal noise floor only (no ICI).
\item \mbox{\hyperlink{namespacemesh__sim_a3e593524f1194ab3632ac6ffbbcb20ee}{Sinr\+To\+Capacity}} and \mbox{\hyperlink{namespacemesh__sim_ad9ccac6586eaef254fffab3f801a7fd0}{Sinr\+To\+Mcs\+Index}} translate SINR to capacity and MCS index using the configured AMC model.
\end{DoxyEnumerate}
