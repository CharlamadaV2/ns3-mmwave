\doxysubsection{Detailed Description}
Translates a \mbox{\hyperlink{structmesh__sim_1_1SimConfig}{Sim\+Config}} into ns-\/3 mobility, building, and propagation model objects. 

Holds a const reference to the \mbox{\hyperlink{structmesh__sim_1_1SimConfig}{Sim\+Config}} — the config must remain valid for the lifetime of the builder. All ns-\/3 smart pointers are retained internally after \mbox{\hyperlink{classmesh__sim_1_1TopologyBuilder_a66846486902eb1ebdee7ad105662759f}{Build}} and returned by the accessor methods.
