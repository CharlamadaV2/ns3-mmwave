Computes radio link quality for every node pair each simulation tick. ~\newline


Given the current node positions and ns-\/3 propagation models, this module produces path loss, SINR, capacity, and MCS for each link, then stores the results in a symmetric matrix for O(1) lookup by the routing and metrics layers.\hypertarget{md__home_kimson_ns3_mmwave_scratch_mesh_sim_src_eval_README_autotoc_md28}{}\doxysection{Output}\label{md__home_kimson_ns3_mmwave_scratch_mesh_sim_src_eval_README_autotoc_md28}
The eval module produces no files. It outputs two in-\/memory data structures each tick\+:

$\ast$$\ast${\ttfamily std\+::vector$<$Link\+Result$>$}$\ast$$\ast$ — returned by {\ttfamily Link\+Evaluator\+::\+Evaluate\+All}. One entry per unordered node pair (N·(N−1)/2 total), in (i $<$ j) index order.

$\ast$$\ast${\ttfamily Link\+Table}$\ast$$\ast$ — populated by {\ttfamily Link\+Table\+::\+Update} from the vector above. A symmetric N×N matrix; {\ttfamily Get(i, j)} and {\ttfamily Get(j, i)} return the same result.

\hypertarget{md__home_kimson_ns3_mmwave_scratch_mesh_sim_src_eval_README_autotoc_md30}{}\doxysection{Conventions}\label{md__home_kimson_ns3_mmwave_scratch_mesh_sim_src_eval_README_autotoc_md30}

\begin{DoxyItemize}
\item {\bfseries{No inter-\/node interference.}} mm\+Wave beams are assumed orthogonal so SINR is computed as received signal power vs thermal noise floor only — no ICI term. The noise floor is\+: {\ttfamily −174 + 10·log₂(bandwidth\+\_\+\+Hz) + noise\+\_\+figure\+\_\+dB}.
\item {\bfseries{Beamforming gain is applied symmetrically.}} {\ttfamily tx\+\_\+array\+\_\+gain\+\_\+d\+Bi + rx\+\_\+array\+\_\+gain\+\_\+d\+Bi} is added to {\ttfamily rx\+\_\+power\+\_\+dbm} as a single combined gain. Both sides use the same antenna model.
\item {\bfseries{Co-\/location guard at 1 m.}} Links with {\ttfamily distance\+\_\+m $<$ 1.\+0} bypass the propagation model entirely (full TX power, zero path loss) to prevent {\ttfamily log10(0)} in distance-\/dependent models.
\item $\ast$$\ast${\ttfamily Evaluate\+All} evaluates upper triangle only.$\ast$$\ast$ Only pairs (i, j) with i $<$ j are evaluated. {\ttfamily Link\+Table\+::\+Update} then mirrors each result to (j, i) so all lookups are symmetric. This halves the number of propagation model calls per tick.
\item {\bfseries{SINR sentinel is −999.0.}} Links that are unevaluated or below the noise floor carry {\ttfamily sinr\+\_\+db = −999.0}. Consumers check {\ttfamily sinr\+\_\+db $>$ −900.0} to filter these out rather than using a boolean flag.
\item {\bfseries{Connectivity threshold is −6.7 dB.}} This matches {\ttfamily SINR\+\_\+\+MIN\+\_\+\+DB} in {\ttfamily \mbox{\hyperlink{sinr-capacity_8h}{sinr-\/capacity.\+h}}} — the minimum SINR for any MCS entry. Links below this have zero capacity and are treated as disconnected by the routing layer.
\item $\ast$$\ast${\ttfamily Link\+Evaluator\+::\+Configure} must be called before any evaluation.$\ast$$\ast$ It caches the noise floor and beamforming gain derived from {\ttfamily Sim\+Config} and stores the propagation model pointers. Calling {\ttfamily Evaluate} or {\ttfamily Evaluate\+All} without configuring first is a null pointer dereference.
