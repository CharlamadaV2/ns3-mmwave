\hypertarget{md__home_kimson_ns3_mmwave_scratch_mesh_sim_src_cli_README_autotoc_md18}{}\doxysection{Conventions}\label{md__home_kimson_ns3_mmwave_scratch_mesh_sim_src_cli_README_autotoc_md18}

\begin{DoxyItemize}
\item {\bfseries{Hard exits on bad input.}} {\ttfamily Parse\+Command\+Line} and {\ttfamily Resolve\+Seeds} call {\ttfamily std\+::exit(1)} with a message to {\ttfamily stderr} rather than throwing. This matches ns-\/3 convention for fatal startup errors and means {\ttfamily sim.\+cc} never needs to handle missing-\/flag cases.
\item {\bfseries{Overwrite-\/safe archiving.}} {\ttfamily Archive\+Scenario\+Inputs} uses {\ttfamily copy\+\_\+options\+::overwrite\+\_\+existing} so re-\/running into the same output directory is safe.
