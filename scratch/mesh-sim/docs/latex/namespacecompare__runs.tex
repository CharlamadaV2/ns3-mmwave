Cross-\/batch summary table\+: one row per validation batch. 

Reads the {\ttfamily validation\+\_\+summary.\+csv} produced by \mbox{\hyperlink{namespacecompare}{compare}} for each batch and prints ranked comparison tables useful for tuning simulation parameters (channel model, TX power, antenna gain).
