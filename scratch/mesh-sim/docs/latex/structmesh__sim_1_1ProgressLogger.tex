\doxysubsection{Detailed Description}
Prints sim-\/time progress, wall-\/clock elapsed time, and ETA to stderr. 

All fields must be set before the first call to \mbox{\hyperlink{structmesh__sim_1_1ProgressLogger_a52f4712a31140e60dfa339dcc38dc1d3}{Tick}}. The struct has no constructor — use aggregate initialisation or set fields directly.

Report progress if this tick falls on a reporting boundary. 

Prints to {\ttfamily stderr} when {\ttfamily tick\+\_\+index} is a multiple of {\ttfamily interval\+\_\+ticks} {\itshape or} when {\ttfamily tick\+\_\+index} equals {\ttfamily total\+\_\+ticks} (ensuring the 100\% line is always printed). All other ticks are a single modulo check and return immediately.

The ETA is estimated as\+: 
\begin{DoxyCode}{0}
\DoxyCodeLine{rate  = wall\_elapsed / sim\_elapsed    (wall seconds per sim second)}
\DoxyCodeLine{eta\_s = (\mbox{\hyperlink{structmesh__sim_1_1ProgressLogger_abed35571192cd76946a4dee37c7128a0}{duration\_s}} -\/ sim\_t) * rate}

\end{DoxyCode}
 ETA is 0 when {\ttfamily sim\+\_\+t} == 0 (avoids division by zero at tick 0).
