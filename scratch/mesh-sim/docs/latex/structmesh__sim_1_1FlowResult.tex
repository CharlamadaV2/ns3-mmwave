\doxysubsection{Detailed Description}
Routing result for one flow at one simulation tick. 

Produced by \mbox{\hyperlink{classmesh__sim_1_1MeshRouter_a5a1a1c0210655e515f0d9c62f592d64b}{Mesh\+Router\+::\+Route}} and consumed by \mbox{\hyperlink{classmesh__sim_1_1MetricsWriter}{Metrics\+Writer}}, \mbox{\hyperlink{classmesh__sim_1_1VizWriter}{Viz\+Writer}}, and the RL reward calculator.

{\bfseries{Effective demand}} {\ttfamily demand\+\_\+mbps} reflects the flow\textquotesingle{}s {\itshape effective} demand this tick — it is zero when the flow is inactive or in the OFF phase of an on-\/off model, regardless of the configured per-\/flow demand. Only the on\+\_\+off model sets {\ttfamily in\+\_\+on\+\_\+phase} to {\ttfamily false}; constant and Poisson flows always have {\ttfamily demand\+\_\+mbps} equal to \mbox{\hyperlink{structmesh__sim_1_1Flow_accd345f898db9ad4f6ac5a5d6a3c9816}{Flow\+::demand\+\_\+mbps}} when active.

{\bfseries{Unroutable flows}} When {\ttfamily routable} is {\ttfamily false} the path is empty, {\ttfamily delivered\+\_\+mbps} is 0, {\ttfamily latency\+\_\+ms} is 0, and {\ttfamily hop\+\_\+count} is 0. The {\ttfamily src} and {\ttfamily dst} fields are always set.

{\bfseries{Self-\/flows}} ({\ttfamily src} == {\ttfamily dst}) are marked {\ttfamily routable} = {\ttfamily true} with an empty path and zero delivered demand, since they require no forwarding.
