{\ttfamily -\/-\/auto-\/waypoints} on {\ttfamily run\+\_\+batch} patches each scenario\textquotesingle{}s {\ttfamily nodes.\+json} in-\/place from its field GPS trace before invoking the sim (skips static-\/rab2 scenarios automatically). The patch is permanent — {\ttfamily git diff inputs/} to see what changed, {\ttfamily git checkout inputs/} to revert.

{\ttfamily build\+\_\+waypoints} reads the field {\ttfamily gps\+\_\+track\+\_\+trace.\+csv} for a scenario, translates to the sim frame using a stationary anchor node (default {\ttfamily rab1}), downsamples the moving node\textquotesingle{}s track to N waypoints, and patches them into the scenario\textquotesingle{}s {\ttfamily nodes.\+json} with {\ttfamily mobility = \char`\"{}waypoint\char`\"{}}. Time modes\+: {\ttfamily raw} (use field clock as-\/is), {\ttfamily clip} (cap at {\ttfamily -\/-\/duration}), {\ttfamily scale} (stretch/compress to {\ttfamily -\/-\/duration}). After patching, rebuild the sim and re-\/run.

{\ttfamily scenario\+\_\+fidelity} reads each scenario\textquotesingle{}s snapshotted {\ttfamily nodes.\+json} + {\ttfamily seed-\/1/positions.\+csv} and the field\textquotesingle{}s {\ttfamily gps\+\_\+track\+\_\+trace.\+csv} (produced by {\ttfamily arpo\+\_\+data.\+cli plot}), then for each rab reports field-\/vs-\/sim bounding box, path length, and mobility class (static / mobile), plus pairwise t=0 distances between rabs. It surfaces mismatches like \char`\"{}rab2 drives a 1.\+7 km loop in the field but the sim has it pinned \`{}fixed\`{}.\char`\"{} The mobility classifier is bbox-\/based (threshold 20 m max-\/dim) so cumulative GPS jitter doesn\textquotesingle{}t trip it.

{\ttfamily compare\+\_\+runs} auto-\/discovers every batch under {\ttfamily outputs/} with a {\ttfamily validation\+\_\+summary.\+csv} (or takes explicit batch dirs) and writes cross-\/batch heatmap PNGs to {\ttfamily outputs/cross\+\_\+batch\+\_\+summary/}. One PNG per (metric, score) — rows = scenarios with date, cols = batches with timestamp, cells = mean across rab links. For multi-\/day variance in the {\bfseries{field}} data itself (independent of any sim run), see {\ttfamily python -\/m scripts.\+arpo\+\_\+data.\+multiday\+\_\+variance}.\hypertarget{scripts_validation_autotoc_md9}{}\doxysubsubsection{How to read the chart}\label{scripts_validation_autotoc_md9}
One axis\+: normalized histograms (densities) of sim and field samples, overlaid. Density normalization (∫=1) lets the curves compare directly even though sim N (tens of thousands) is much larger than field N. The shaded band on the sim curve is a pointwise bootstrap CI (default 90\%, B=1000).

Subtitle annotates the K-\/S D-\/statistic and $\vert$Δmedian$\vert$/$\vert$Δmean$\vert$ in the metric\textquotesingle{}s units. K-\/S is unitless (0–1) — useful for ranking similarity across runs; $\vert$Δmed$\vert$ / $\vert$Δmean$\vert$ are in the metric\textquotesingle{}s own units. Median is the robust central-\/tendency (skewed wireless metrics + bursty fades drag the mean around); mean is reported alongside it so you can see when they diverge.

The K-\/S p-\/value is intentionally not reported\+: with N in the tens of thousands per pool, p ≈ 0 even for operationally trivial differences.\hypertarget{scripts_validation_autotoc_md10}{}\doxysubsubsection{Output}\label{scripts_validation_autotoc_md10}

\hypertarget{scripts_validation_autotoc_md12}{}\doxysubsubsection{Conventions}\label{scripts_validation_autotoc_md12}

\begin{DoxyItemize}
\item {\bfseries{Distributional comparison, not temporal.}} Sim and field samples are pooled raw (no smoothing, no time alignment). The comparison is over the marginal distribution of each metric.
\item {\bfseries{MCS cap.}} Sim MCS is post-\/capped at 12 to match the field firmware limit before any comparison is made.
\item {\bfseries{Sim trace MAC columns are empty.}} {\ttfamily sim\+\_\+to\+\_\+traces} leaves {\ttfamily tag\+\_\+local\+\_\+mac}, {\ttfamily tag\+\_\+sta\+\_\+mac}, and {\ttfamily tag\+\_\+interface} blank — the sim has no per-\/antenna identity.
\item {\bfseries{Scenario name mapping.}} Sim names translate to field names by stripping {\ttfamily arpo-\/}, joining the middle tokens with {\ttfamily \+\_\+}, and upper-\/casing single-\/letter family tokens\+: {\ttfamily arpo-\/1-\/x-\/misc-\/04172026} → {\ttfamily 1-\/X\+\_\+misc\+\_\+04172026}.
\item {\bfseries{NaN rows in {\ttfamily validation\+\_\+summary.\+csv}}} mean the field collect did not capture telemetry for that link (e.\+g. rab2 and rab3 were not beam-\/paired during the scenario). This is expected for some scenarios and is not a pipeline error.
\item $\ast$$\ast${\ttfamily -\/-\/auto-\/waypoints} mutates {\ttfamily inputs/}.$\ast$$\ast$ The patch is permanent for the duration of the run. Use {\ttfamily git diff inputs/} to review and {\ttfamily git checkout inputs/} to revert.
\item $\ast$$\ast${\ttfamily build\+\_\+waypoints} mobility classifier is bbox-\/based$\ast$$\ast$ (threshold\+: 20 m max bounding-\/box dimension). Path length alone is GPS-\/noise-\/prone and would misclassify jittery static nodes as mobile.
\end{DoxyItemize}\hypertarget{scripts_validation_autotoc_md13}{}\doxysubsubsection{Dependencies}\label{scripts_validation_autotoc_md13}
