CLI entry point for the batch runner. 

Full workflow\+:
\begin{DoxyEnumerate}
\item Discover scenarios under {\ttfamily -\/-\/scenarios-\/dir}.
\item Locate the sim binary (auto-\/detect or {\ttfamily -\/-\/sim-\/binary}).
\item For each scenario (optionally filtered by {\ttfamily -\/-\/only})\+:
\begin{DoxyEnumerate}
\item Optionally patch waypoints via patch\+\_\+scenario\+\_\+waypoints.
\item Invoke the sim via \mbox{\hyperlink{namespacescratch_1_1mesh-sim_1_1scripts_1_1validation_1_1run__batch_aa92a78132f8a48a967e63416ee10731b}{\+\_\+run\+\_\+one}}.
\item Append the result to {\ttfamily batch\+\_\+manifest.\+json} (written after every run so a crash doesn\textquotesingle{}t lose partial results).
\end{DoxyEnumerate}
\item Print a final OK/failed count.
\end{DoxyEnumerate}
