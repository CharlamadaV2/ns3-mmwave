\doxysubsection{Detailed Description}
Day-\/vs-\/day comparison for the same scenario family. 

Pools per-\/day trace CSVs at the (link, metric) level, then renders ECDF overlays and computes two-\/sample K-\/S distances for every day pair. Antenna identity is dropped here — drill into the per-\/day plots if you need per-\/radio breakdown.
