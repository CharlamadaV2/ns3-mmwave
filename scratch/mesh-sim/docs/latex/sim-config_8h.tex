\doxysubsection{Detailed Description}
Top-\/level simulation configuration and runtime metadata POD types. 

Sim\+Config is the single root object that flows through the entire simulation. It is produced by Config\+Loader\+::\+Load, validated by Validate\+Config, and then passed by const-\/reference to every subsystem constructor. Timing\+Info is intentionally separate from Sim\+Config because it is not loaded from any file — it is populated by {\ttfamily sim.\+cc} after the step loop completes and written to the output JSON by {\ttfamily Metrics\+Writer}.
