\doxysubsection{Detailed Description}
Reinforcement-\/learning controller configuration. 

When {\ttfamily enabled} is {\ttfamily false} every other field is ignored. When {\ttfamily true} the sim exchanges JSON observations and actions with an external RL agent via stdin/stdout at each tick (activated by the {\ttfamily --rl-\/mode} CLI flag).
