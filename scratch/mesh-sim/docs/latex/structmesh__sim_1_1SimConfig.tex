\doxysubsection{Detailed Description}
Root simulation configuration aggregating all subsystem parameters. 

Produced by \mbox{\hyperlink{classmesh__sim_1_1ConfigLoader_af4aedd6c4bb1368e4ac53e7483b19809}{Config\+Loader\+::\+Load}} from {\ttfamily run.\+ini} and the JSON files it references. Validated by \mbox{\hyperlink{namespacemesh__sim_a09050ff52e549176ef6ec6f11b137eea}{Validate\+Config}} before any ns-\/3 objects are constructed. Passed by const-\/reference to every subsystem constructor.

{\bfseries{Timing parameters}}
\begin{DoxyItemize}
\item {\ttfamily tick\+\_\+s} must be ≤ {\ttfamily duration\+\_\+s}.
\item {\ttfamily warmup\+\_\+s} samples are excluded from all output metrics but the simulation still runs for the full {\ttfamily duration\+\_\+s}.
\item {\ttfamily viz\+\_\+tick\+\_\+ms} controls how frequently CSV position/link snapshots are written; it is independent of {\ttfamily tick\+\_\+s}. 
\end{DoxyItemize}
