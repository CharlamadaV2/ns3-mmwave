\doxysubsection{Detailed Description}
Minimal INI-\/file parser used by Config\+Loader. 

{\bfseries{Format rules}}
\begin{DoxyItemize}
\item Comments\+: everything from the first {\ttfamily \#} or {\ttfamily }; to the end of the line is stripped before processing.
\item Section headers\+: {\ttfamily }\mbox{[}name\mbox{]} — the section name is trimmed of whitespace.
\item Key-\/value pairs\+: {\ttfamily key=value} — split on the {\itshape first} {\ttfamily =} sign; both key and value are trimmed of whitespace.
\item Lines without an {\ttfamily =} sign (and that are not section headers) are silently skipped.
\item Keys that appear before any {\ttfamily }\mbox{[}section\mbox{]} header are stored under the empty-\/string section key {\ttfamily \char`\"{}\char`\"{}}. 
\end{DoxyItemize}
